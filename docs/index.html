Dave Cross

Perl trainer, consultant, and author

Dave has been programming professionally since 1988, and using Perl since 1996 — as a glue language, for web development, and as a general-purpose language. He's the author of Data Munging with Perl (Manning, 2001) and a co-author of Perl Template Toolkit (O'Reilly, 2003).

He's run Perl training courses since 2001, for organisations ranging from investment banks to startups, and speaks regularly at Perl and open source conferences. In 1998 he founded the London Perl Mongers — the first Perl user group in Europe — and later served as the Perl Foundation's International User Groups Co-ordinator, earning a White Camel award in 2004 for his services to the Perl community.
